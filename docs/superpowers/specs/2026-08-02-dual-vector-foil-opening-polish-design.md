# DualVectorFoil 开头钩子 + 电影感升级 设计

> 2026-08-02 | 针对"画面太单调、观众几秒划走"反馈 | 方案一：电影感升级

## 目标

B站/YouTube 横屏 16:9。保留叙事结构，重点解决开头留存与画面质感：

1. **开头 0-8s 重做**：信封大小的二向箔特写，不断长大，呼应小说"从信封大小不断变大"
2. **标题柔和浮现**：不突兀
3. **电影后期质感**：胶片颗粒 / 暗角脉动 / 镜头光斑
4. **行星二维化光晕强化**

## 改动明细

### 1. 开场特写（0-8s，p=0~0.1）

- **0-2s**：黑屏，一枚信封大小的二向箔（scale≈0.02，约 3.6 单位）缓缓漂入特写。边缘被空间光照亮，表面虹彩反光。镜头贴近（约 8 单位远）。
- **2-5s**：「二向箔」标题柔和浮现，箔片开始长大、缓慢旋转。
- **5-8s**：箔片从信封大小连续长大，镜头后退，太阳系在箔片背后浮现。

实现：
- `Foil` 组件改为**第 0 帧即存在**，`visible` 恒 true。`grow` 改为从 0.02 起连续长到 1.0。
- `foilZ` 开场改为近处（箔片贴近镜头），随长大/扫掠移到远处扫过太阳系。
- `cameras.ts` 新增 `S_OPEN`（0-0.1）：镜头贴近小箔片 → 后退。
- 3D 场景无需新对象，复用现有箔面（180×180 平面，scale 缩放即为大小变化）。

### 2. 标题柔和浮现

- 不用 spring "砸入"，改用**淡入 + 光晕扩散 + 字距收拢**，约 1s 内自然亮起。
- 淡入帧 ~8-30，光晕 blur 从 10→40，字距从 0.8em→0.4em。
- 无白闪、无缩放弹跳。

### 3. 电影后期质感（全片叠加）

- **胶片颗粒**：动态噪点（canvas 生成随机噪点，低透明度 ~0.05，微动）。
- **暗角脉动**：四周径向渐暗，随箔面扫掠缓慢呼吸（透明度 0.25→0.5）。
- **镜头光斑**：高光处横向光晕（CSS 叠加，低透明度）。

### 4. 行星二维化光晕

- 每颗行星被摊平时，二维画背后加一圈扩散光晕（glow sprite），增强层次。

### 5. 旁白与字幕衔接

- **旁白延迟 120 帧（4s）开始**：开场 0-4s 做静默冷开场（BGM + 箔片特写 + 标题），避免旁白 s1（讲太阳系/掩体计划）与箔片特写画面错位。
- 旁白 `<Audio>` 用 `<Sequence from={120}>` 包裹。
- 字幕 `SEGMENTS` 全部 +120 帧；s1 从 frame 120 开始。
- 尾声「《三体III》署名」顺延到 frame ~2270-2400。
- 不加开场氛围字幕（旁白本身会交代"薄如蝉翼的纸片"，在 s2 段）。
